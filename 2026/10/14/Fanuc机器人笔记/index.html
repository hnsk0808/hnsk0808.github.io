Fanuc机器人笔记

机器人型号

选择Fanuc LR Mate 200iD

Roboguide 扩展

  1. 添加码垛扩展：机器人选项添加J500
  2. 添加ModbusTCP扩展：机器人选项添加R581和R800

主站，从站概念

从站可以看作服务器

主站可以看作客户端

示教器设置主机通信

  1. 进入页面Menu -> 6 设置 -> 0 下页 -> 5 通信
  2. 如果没有看到TCP/IP协议，选择F4 显示 -> 1 协议，有显示跳过这一步
  3. 选择TCP/IP，点击F3 详细
  4. 配置端口#1 IP地址
  5. 配置主机，添加PLC名称和PLC的IP地址
  6. 选中PLC的IP地址后，选择F4 PING测试连接是否成功

示教器设置Modbus TCP 参数

机器人只能作为 Modbus TCP从站，最多被 4 个主站访问

默认端口号：502

  1. 进入页面Menu -> 5 IO -> 1 单元接口 -> 3 Modbus TCP
  2. 设定连接的数量，最大可以设为4，设为0表示不允许主机访问
  3. 设定超时，0表示不检查连接的状态，单位ms
  4. 设定报警严重程度，可以选择设置失联时触发动作
  5. 设定超时状态下保持输入，无效时输入端口状态为0，有效时输入端口状态为最后一次的值
  6. 设定输入字数和输出字数，单位为字（2字节=16位），需与PLC端设定一致

可以改动默认端口号

示教器设置Modbus TCP的 I/O 地址分配

Modbus TCP 协议支持 DI/DO 地址分配

机架号：96，槽位号：1

机器人端不能写入 DO，只能写入 DI

机器人使用小端方式存储通信数据

PLC 使用 Modbus_TCP FB块

  1. Input IP_ADDR[4]: Byte 保存目标IP地址
  2. Input 通信ID: Int 保存通信ID，范围1-4095
  3. InOut Send_Data和Receive_Data，类型都为Variant
  4. 使用DB块MB_CLIENT进行通信



PLC 设定时钟脉冲

  1. 在项目树中双击 “设备与网络”，打开PLC的设备视图。
  2. 选中CPU，在下方属性窗口中找到 “系统和时钟存储器” 选项。
  3. 勾选 “启用时钟存储器字节”，并为其分配一个未被使用的M存储字节地址，例如 10（代表MB10）。
  4. 配置后，该字节的各个位会自动生成不同频率的脉冲。位0（M10.0）即为10Hz时钟脉冲。

PLC 设定首次循环

  1. 同样在CPU属性的 “系统和时钟存储器” 页面中。
  2. 勾选 “启用系统存储器字节”，并分配一个字节地址，例如 1（代表MB1）。
  3. 配置后，该字节的位0（M1.0）即为FirstScan位。
